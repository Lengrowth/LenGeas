The schema registry interface is the immutable schema release manifest, canonical bundle digest, generated import paths, and validator/canonicalizer commands in `docs/evidence/phase-04/handoff.md`. Python and TypeScript expose Draft 2020-12 structural bundle validation; the Python CLI also applies semantic and safety checks. The signed release records normalized schema catalog SHA-256 `6398ea5ac5b6880b567d127b8e3e03f2f85200034376673da079052031b3b1a8` and minimal bundle SHA-256 `c2dce5b74509d7afa505876247d8cbb400c965c51ef9f00b374cfca91872c953`. The signature verifies against the included public key and detects content changes, but that key has no independent trust anchor and does not authenticate signer identity. Registry publication is deferred because no registry endpoint or secret name is configured. No external publish was attempted.
