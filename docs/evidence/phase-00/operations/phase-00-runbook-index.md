# Phase 00 Operations Evidence

## State

`accepted`

The architecture and handoff identify the operational authorities, on-call roles, alerts, and runbook families required by the existing SRE and operations contracts. Exercised runbooks are not claimed in this documentation-only phase; they remain later-phase evidence.

## Required families

- API errors and latency
- Atlas degradation and restore
- cache failure
- queue backlog and Kafka lag
- outbox and timer backlog
- Cloudflare and R2 failure
- authentication outage and key rotation
- purchase provider failure and ledger imbalance
- realtime capacity and AZ/region loss
- compromised credential and bad release
- privacy request failure
