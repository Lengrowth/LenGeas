# Phase 00 Performance Baseline

- Status: `accepted`
- Scope: documented budgets and SLOs only; no product code exists to benchmark

The locked targets are API p95 at most 250 ms, API p99 at most 750 ms, realtime accepted-input p99 at most 50 ms in-region, 99.95% player/API availability, 99.9% Studio availability, and the runtime/evaluator budgets recorded in `docs/06-runtime-and-rules.md`. Load qualification is a later-phase gate and is not claimed here.
